# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **Wise Memory Optimizer Native**, please report it responsibly by opening a security advisory on GitHub or opening a private issue.

All security vulnerabilities will be promptly reviewed and patched.
